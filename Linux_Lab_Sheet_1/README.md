# Linux Administration Lab Sheet - 1 (DCS583)

Solutions for all 50 questions. Each question is saved in its own separate `.txt` file.

## Files
- `Q01.txt` to `Q20.txt`: Easy questions
- `Q21.txt` to `Q35.txt`: Medium questions
- `Q36.txt` to `Q50.txt`: Hard / Challenge questions

## How to use
Open each file to view the original question title, command/code, and a short explanation.
Commands are intended for Ubuntu/Linux. Check paths before running commands that move or delete files.

## Upload to GitHub
1. Download and extract the ZIP archive.
2. Open your GitHub repository.
3. Select **Add file → Upload files**.
4. Upload the extracted files and `README.md`.
5. Commit the changes.
