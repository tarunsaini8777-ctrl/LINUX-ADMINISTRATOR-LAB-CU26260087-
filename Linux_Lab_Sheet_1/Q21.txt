QUESTION 21
Create students.txt and add five names using echo and >>

CODE / COMMAND:
cd ~
echo "Rahul" > students.txt
echo "Aman" >> students.txt
echo "Priya" >> students.txt
echo "Rohit" >> students.txt
echo "Neha" >> students.txt

EXPLANATION:
Creates a five-line file. > creates/overwrites; >> appends.
