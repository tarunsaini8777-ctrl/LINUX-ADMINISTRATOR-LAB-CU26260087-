QUESTION 39
Create test.sh, add a comment about rwxr-xr--, and make it executable

CODE / COMMAND:
#!/bin/bash
# rwxr-xr-- means owner: read/write/execute, group: read/execute, others: read only.
echo 'Linux lab test script'
chmod +x test.sh
ls -l test.sh

EXPLANATION:
Save these lines as test.sh, then run chmod +x test.sh separately in the terminal. chmod +x adds execute permission but does not set the exact rwxr-xr-- mode.
